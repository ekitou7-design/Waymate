比较基线：此前 `Waymate_RC_Cardinal_Display.map`；旧 Startup Experiment 同时复核。最终来源：交付 .map + ESP-IDF size 工具。下表是静态链接报告，不是运行时空闲堆。

| 指标（字节） | Startup Experiment | Cardinal 基线 | Final RC2 | 相对 Cardinal |
| --- | ---: | ---: | ---: | ---: |
| Internal .data | 38,464 | 38,464 | 38,464 | +0 |
| Internal .bss | 95,120 | 95,120 | 95,128 | +8 |
| Internal .text | 110,795 | 110,795 | 110,795 | +0 |
| Vectors | 1,028 | 1,028 | 1,028 | +0 |
| 静态 D/IRAM 总占用 | 245,407 | 245,407 | 245,415 | +8 |
| 链接报告剩余 | 96,353 | 96,353 | 96,345 | -8 |

| Flash 非 RAM | 1,278,908 | 1,281,516 | 1,290,932 | +9,416 |

静态 Internal RAM 增加 **8 字节**，来自 Presenter 的固定相机状态；数据区、驱动、任务栈和大缓冲配置未扩大。总 Internal RAM 341,760 字节，链接剩余 96,345 字节。这不等于运行时最小空闲堆。

## LVGL 主机渲染对照

同一 macOS 主机、同一 466px renderer、320 行部分绘制缓冲、64 KiB 基础池及模拟 2 MiB 补充池。没有改变实体板的内存配置，也没有把这次主机补充池作为 PSRAM 实验合入固件。

| 场景（字节） | 基线 | Final RC2 | 变化 |
| --- | ---: | ---: | ---: |
| Stage C.2 使用 | 58,248 | 59,072 | +824 |
| Backtrack 使用 | 58,456 | 59,344 | +888 |
| 完整产品状态峰值 | 66,592 | 67,472 | +880 |

UI 复用固定路线数组、现有控件和字体，新增无几何提示标签；不做每帧地图瓦片、SDK 或大位图分配。路线最多 24 点，周边场景沿用既有容量。投影计算纬度缩放一次，既有 25ms 插值只移动已分配的点。

主机 Backtrack 256 点 / 4 段 / 100 次投影与渲染耗时约 198ms；用于回归检视，不是 ESP32 帧率。基线与候选耗时会受主机负载影响，不据此声称性能提升。
