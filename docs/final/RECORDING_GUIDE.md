# 不出门录制 Waymate 演示

## 纯软件录屏

可以录制 iPhone 模拟器或手动安装后的手机 Demo。无需圆屏、网络、GPS 或移动，真实 BLE 连接状态不会伪造。

1. 首页“更多 → Demo Mode · 演示模式”。保留画面中的 DEMO 和模拟圆屏说明。
2. 默认场景按“开始”：0–4 秒模拟规划；5–43 秒导航，含 320→200→150→100→50m、右转／左转与到达；44–63 秒记录模拟 Ride；64–84 秒沿模拟已记录轨迹返回。
3. 可先暂停，用“下一步”逐帧讲解；Navigation / Ride / Backtrack 快速跳转，重播重新开始。单独选择左转、直行、连续弯道或掉头拍补充镜头。
4. 退出后回到首页，展示没有新增真实 History。勿把模拟路线规划称为在线高德实际请求。

`Previews/iPhone/` 为实际模拟器截图；`Previews/LVGL/` A–F 为实际共享 Presenter → LVGL 帧缓冲导出。可用作 UI 示意，字幕标明“模拟输入 / 软件渲染”，不是实体屏拍照或真实道路测试。

## 手机＋实体圆屏

先按安装说明由用户手动更新 App 和 ESP32，再完成冷启动、BLE、Demo、重连和内存检查。连接成功后，Demo 通过既有 BLE v1 驱动实体屏；手机仍持续显示模拟标记，最终固件也显示 DEMO。

建议拍摄顺序：正常开机 → 真实连接状态 → 进入 Demo → 完整导航 / Ride / Backtrack → 暂停讲解一个连续弯道 → 退出 → 正常首页和原 History。机位同时包含手机与圆屏；不需要骑车。

旧固件可以接收兼容数据，但不会显示最终微型地图或可靠新 DEMO 角标。录制新设计的实体屏必须更新 ESP32；只更新手机只改变手机界面。

当前交付具备可信的软件 UI 录制条件。实机视频、完整产品比赛提交素材由用户录制；本轮没有编造照片、道路录像或物理连接成功。
