# Waymate 最小产品基线

**文档状态：** Waymate v1 产品基线

**目标硬件：** Waveshare ESP32-S3-Touch-AMOLED-1.75C（带电池版本）

**当前原则：** Waymate v1 正式使用 Waveshare ESP32-S3-Touch-AMOLED-1.75C。iPhone 是主要的定位、联网和导航数据来源；圆屏是骑行 Companion Display。当前不做设备端独立 GNSS，不修改现有 ESP32 1.75C 硬件驱动、BLE 协议或既有功能代码。

## 1. 产品定位

Waymate 是一个面向骑行场景的圆屏 Companion Display 及 iPhone 协同系统。第一版建立在当前 MOTO GPS 衍生项目和 1.75C 固件基线上，优先保持已有的 iPhone 导航体验，再增加由 iPhone 驱动的轨迹记录、圆屏轨迹显示和原路回溯。

第一版不把设备定义为独立手机或独立导航终端。搜索、路线规划、定位、联网和主要导航决策均以 iPhone 为主；圆屏负责在骑行中提供低干扰的信息显示、触摸交互和轻量提示。

## 2. 已有功能基线

| 功能 | 主要归属 | 定位/联网来源 | 第一版处理 |
|---|---|---:|---|
| iPhone 通过 BLE 向圆屏发送导航信息 | 手机 + 设备 | iPhone 定位、联网和导航状态 | 保留 |
| 转向、距离、速度、方向显示 | 圆屏显示；数据主要来自 iPhone | iPhone | 保留 |
| 466×466 圆屏触摸 UI | 设备本地 | 不需要独立定位 | 保留 |
| BLE 通信 | 手机 + 设备 | 不需要独立定位 | 保留 |
| iOS 搜索、路线和导航 | 手机 | iPhone Core Location、网络和导航服务 | 保留，iPhone 为第一优先平台 |
| 音乐控制 | 手机 + 设备交互 | iPhone 音乐能力 | 保留 |
| IMU | 设备本地 | 不需要独立定位 | 保留，用于方向辅助和运动感知 |

已有导航显示继续采用“iPhone 计算、圆屏显示”的基本模式。第一版不因为未来可能的功能扩展而加入设备端独立定位链路。

## 3. 计划新增功能

| 功能 | 主要归属 | 是否需要设备端独立 GNSS | 规划状态 |
|---|---|---:|---|
| iPhone 记录骑行轨迹 | iPhone | 否，使用 iPhone 定位 | v1 计划功能 |
| 圆屏显示骑行轨迹 | 手机计算/传输 + 圆屏显示 | 否，轨迹来自 iPhone | v1 计划功能 |
| 基于手机轨迹实现 Backtrack | iPhone 计算 + 圆屏提示 | 否，使用 iPhone 轨迹 | v1 计划功能 |
| 骑行里程、速度、时间等数据 | iPhone 统计 + 圆屏展示 | 否，使用 iPhone 定位和导航数据 | v1 计划功能 |
| “Can you hear me?” 同行骑手提示 | iPhone 会话 + 圆屏提示 | 否 | v1 计划功能，先做短提示 |
| 自定义表盘、纪念日、天气、耳机连接状态 | iPhone 数据/状态 + 圆屏轻量展示 | 视具体功能而定 | 后续轻量扩展 |
| Android / 荣耀手机支持 | 后续手机端 | 由手机端提供 | 可选后续方向 |

### 3.1 iPhone 轨迹记录

iPhone 负责采集、保存和管理骑行轨迹。第一版优先支持开始、暂停、继续、结束、查看、清除和导出等基本生命周期，不要求设备独立保存完整轨迹。

### 3.2 圆屏轨迹显示

圆屏作为 Companion Display，显示来自 iPhone 的轨迹摘要或当前轨迹窗口。第一版重点是骑行中的可读性和低干扰，不要求在设备端运行完整地图数据库。

### 3.3 基于手机轨迹的 Backtrack

Backtrack 使用 iPhone 已记录的轨迹计算返回方向、距离和简单的原路提示，再通过现有圆屏显示链路呈现。第一版不要求设备端独立 GNSS、不要求独立离线地图，也不要求道路级重规划。

### 3.4 骑行数据与轻量情绪化 UI

第一版优先展示本次骑行里程、当前速度、平均速度、骑行时间等基础数据。后续可以在不改变核心导航职责的前提下，加入自定义表盘、纪念日、天气、耳机连接状态和其他轻量情绪化 UI。

### 3.5 “Can you hear me?”

第一版将其定义为同行骑手之间的短提示事件，而不是即时语音通信：

- 由 iPhone 管理同行会话或提示发送；
- 圆屏显示或播放简单提示；
- 支持接收、确认、限频和断连状态；
- 暂不加入麦克风、持续监听或双向语音通话。

## 4. 设备本地功能与手机依赖

### 4.1 设备本地功能

- 圆屏显示、触摸和页面切换；
- BLE 连接状态和设备侧通信；
- IMU 采样和方向辅助；
- 来自 iPhone 的导航、轨迹、回溯和骑行数据展示；
- 音乐控制和同行提示的设备侧交互；
- 后续轻量表盘和状态卡片展示。

### 4.2 依赖手机的功能

- 地点搜索；
- 路线规划和路线选择；
- 定位、联网和导航状态产生；
- iPhone 轨迹记录、存储、回溯计算和数据管理；
- 现有地图和后端服务；
- Apple Music 等 iOS 音乐控制；
- 同行提示会话管理；
- 天气、耳机连接状态等后续轻量数据来源。

### 4.3 两端共同承担的功能

- BLE 连接和数据传输；
- 导航状态同步；
- iPhone 轨迹摘要或轨迹窗口的显示；
- Backtrack 状态和提示同步；
- 轨迹查看和管理；
- 同行骑手提示的发送、接收和确认。

## 5. 暂时明确不做

以下内容不属于当前最小开发基线：

- 1.75-G 适配和迁移；
- 修改现有 ESP32 硬件驱动；
- 修改或扩展当前 BLE 协议；
- 设备端独立 GNSS、GNSS 驱动和 GNSS 天线适配；
- 独立于手机的完整搜索、路线规划和地图系统；
- 第一版 Android 或荣耀手机正式支持；
- 即时语音通话或复杂音频通信；
- 云端账号、社交网络和骑行数据平台；
- 大规模 MOTO GPS → Waymate 重命名；
- 删除或替换 LICENSE、NOTICE 和原作者署名。

## 6. 当前技术边界

当前代码和 Waymate v1 均以 Waveshare ESP32-S3-Touch-AMOLED-1.75C 和 iPhone 为正式基线。1.75-G 迁移计划暂缓，仅作为未来参考；设备端独立 GNSS 也暂不属于当前产品方向。

Waymate 的第一版应优先保证：现有 iPhone 导航链路不被破坏，圆屏作为 Companion Display 稳定提供导航、轨迹、回溯、音乐和轻量状态展示。
